# User journeys

Canonical screen steps and states live in [UX specification](../03-design/UX-SPEC.md#main-flows), rather than a second editable copy.

Preserve these journeys during rebuilding: create/select a profile; create a book; research and select titles; approve/restore a blueprint; write with budget/retry/restart controls; import/edit/check a manuscript; prepare a cover; export/preflight a pack; prepare marketing; change settings and recover a backup. Automated mock acceptance lives in tests/e2e/. Live prose/publishing acceptance remains separate.
