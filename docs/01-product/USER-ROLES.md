# User roles

The current local application has one owner, Gideon, and author profiles/pen names managed by that owner. A pen name is book metadata, not a separate authenticated account. The server resolves a local owner context; public login/account recovery is not implemented.

Future multi-user accounts remain roadmap scope. Workspace ownership checks must remain at the server boundary even in local mode. See [permissions](../05-security/PERMISSIONS.md) and [product modules M1-M13](PRODUCT-SPEC.md).
