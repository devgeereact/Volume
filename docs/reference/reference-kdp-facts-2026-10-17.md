# KDP facts supplement, 17 October 2026

Only the colour facts below were read on 17 October 2026. Every other rule keeps its own verification date (3 or 6 October 2026). Each page was read on kdp.amazon.com twice that day, and both reads gave the same numbers.

- **12.1, confirmed:** standard colour ink paperback on amazon.co.uk, 72 to 600 pages: 0.85 GBP per book plus 0.020 GBP per page for regular trim, and 0.85 GBP plus 0.027 GBP per page for large trim. Large trim means more than 6.12 inches (155.5 mm) wide or more than 9 inches (228.6 mm) high. The black-ink rows on the same read matched FACTS 3.3. [KDP printing cost](https://kdp.amazon.com/en_US/help/topic/G201834340).
- **12.2, confirmed:** premium colour ink paperback on amazon.co.uk: 24 to 40 pages is a flat 2.59 GBP (regular trim) or 3.24 GBP (large trim) per book; 42 to 828 pages is 0.85 GBP per book plus 0.0435 GBP per page (regular) or 0.0598 GBP per page (large). [KDP printing cost](https://kdp.amazon.com/en_US/help/topic/G201834340).
- **12.3, confirmed:** in the paperback trim table, the columns "Standard color ink and white paper" and "Premium color ink and white paper" give these ranges for the seven Volume trims. Standard colour allows 72 to 600 pages on all seven. Premium colour allows 24 to 828 pages on 5 x 8, 5.25 x 8, 5.5 x 8.5, 6 x 9 and 7 x 10, and 24 to 590 pages on 8.5 x 8.5 and 8.5 x 11. The page states that standard colour is unavailable for Amazon.co.jp. [KDP trim table](https://kdp.amazon.com/en_US/help/topic/GVBQ3CMEQW3W2VL6).
- **12.4, partial:** the same trim table lists colour ink only in white-paper columns, and its only cream-paper column is black ink. The page does not say in prose that colour is unavailable on cream paper, so Volume treats white as the only colour paper and the KDP set-up screen must confirm it. [KDP trim table](https://kdp.amazon.com/en_US/help/topic/GVBQ3CMEQW3W2VL6).
- **12.5, confirmed:** spine width for colour books is page count x 0.002252 inches (0.0572 mm) for standard colour paper and page count x 0.002347 inches (0.0596 mm) for premium colour paper. The black-and-white values on the same read matched FACTS 3.9. [KDP cover guide](https://kdp.amazon.com/en_US/help/topic/G201953020).

No UK colour worked example is on the printing cost page, so Volume's colour cost tests use its own examples built from 12.1 and 12.2.

The supplement is summarised from the official pages, without copying page text beyond column headings. The dated configuration is `config/kdp-rules/2026-10-17.json`.
