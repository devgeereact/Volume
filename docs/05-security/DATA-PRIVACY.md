# Data privacy

Manuscripts, author biographies/photos, prompts and credentials can be sensitive. The existing [security policy](SECURITY.md) remains authoritative for retention, network and file handling. Only the selected provider receives the content required for an authorised request.

Migration/test work uses synthetic fixtures, never copies the owner's .env or data/ into a new checkout, and never logs configuration values. Backup/recovery instructions are in [operations](../07-operations/BACKUP-RECOVERY.md). External privacy/legal acceptance is not established by a local test suite.

What Volume collects, where it goes, cookies and browser storage, proposed retention and what each user stage needs: [privacy inventory](PRIVACY-INVENTORY.md). Draft privacy notice (not for publication): [legal/PRIVACY-NOTICE.draft.md](legal/PRIVACY-NOTICE.draft.md).
