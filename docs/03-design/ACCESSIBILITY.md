# Accessibility

Canonical visual/interaction requirements: [design system](DESIGN-SYSTEM.md#accessibility-floor). Keep semantic landmarks, one screen heading, labelled controls, visible focus, logical keyboard navigation, 44 px touch targets, reduced motion and readable light/dark contrast.

The shell retains its skip link, focus-trapped mobile navigation and Escape dismissal. Editor interaction and route/error states must be tested after reconstruction. Automated browser smoke and screenshots support acceptance; physical screen-reader/device checks remain NOT TESTED unless separately recorded. Migration does not establish full WCAG conformance.
