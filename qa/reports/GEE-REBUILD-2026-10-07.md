## Restore and run

From the candidate directory, review configuration, then:

```sh
mise trust mise.toml
mise install
mise exec -- npm run setup
mise exec -- npm run doctor -- --ports
mise exec -- npm run dev
```

Default web: http://127.0.0.1:5180. API: http://127.0.0.1:5181. These are startup addresses, not a claim that the candidate has been left running. Tests use disposable ports/data and stop their own processes. An existing listener causes a clear failure; it is never killed automatically.
